# note-centric-research

A Claude Code skill describing how I do theoretical physics research and how I write:
the note as the single, all-knowing core of a project, and a way of writing in which
nothing jumps. The skill itself is `SKILL.md`.

## Install

```bash
git clone https://github.com/waibiwaibig/note-centric-research.git ~/projects/note-centric-research
ln -s ~/projects/note-centric-research ~/.claude/skills/note-centric-research
```

Claude Code picks it up in new sessions. Edits in the clone take effect directly.
